讀 IVE 嗰陣，我用 Java 寫咗個 Android app 交 **ITP4501** 功課。入面係數字推理選擇題，每題都有計時。揀完即刻知啱唔啱，揀錯會顯示正確答案。

我用 SQLite 儲題目同每次測驗嘅分數。做完一份會見到總分，下次開 app 仲可以睇返成績表，用棒形圖比較今次同之前差幾多分。

呢份功課我學得最多嘅係點樣將 Java、Android 畫面同 SQLite 接埋。喺答題嗰頁計到嘅分，要儲好先可以喺成績表搵得返。
