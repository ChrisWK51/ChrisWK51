## 簡介

我跟 Vercel 嘅 Next.js 官方教學整咗個 Dashboard，試吓點樣由資料一路做到畫面。程式用 TypeScript，介面用 Tailwind CSS，最後部署喺 Vercel。

## 功能

- Dashboard 會按螢幕闊度調整排版。
- 用 TypeScript 喺開發時檢查型別。
- 用 Next.js 喺伺服器渲染頁面，亦用到靜態頁面生成。
- 用元件展示、管理資料，再經 Vercel 自動建構同部署。

## 學到啲咩

呢次將平時分開學嘅嘢放埋一齊用。寫 React 元件嗰陣要定好資料型別，又要諗邊部分交畀伺服器渲染；排好畫面之後仲要試埋部署。跟足一次流程，對下次自己寫一個大啲嘅全端 project 有幫助。
