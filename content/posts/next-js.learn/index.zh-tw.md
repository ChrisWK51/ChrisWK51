想試吓用 Next.js 寫全端網站，我就跟住 Vercel 官方教學做咗個 Dashboard。由寫 React 元件到最後放上 Vercel，成個流程都自己行咗一次。

畫面用 Tailwind CSS 排，手機同電腦有唔同闊度都睇到。寫元件就用 TypeScript，傳入去嘅資料型別啱唔啱，開發嗰陣已經可以檢查。

我今次想學嘅仲有頁面點樣產生：有啲可以預先生成，有啲要等伺服器攞到資料先畫。跟住教學兩種都試到，做完再交畀 Vercel 自動 build 同部署。
